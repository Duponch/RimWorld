## Décisions et incertitudes

Vêtements complexes : coût retenu **600**, sans prérequis. Le XML porte `ClassicStart` : **Crashlanded commence normalement avec ce savoir**. Notre petit camp est un scénario personnalisé où ce projet commence à zéro, pour offrir une progression réelle ; ce choix ne doit pas être décrit comme le départ standard de RimWorld. La tenue tribale reste initiale. Difficulté et écart technologique entre factions restent neutres (×1), faute de ces systèmes ; pas de pénalité tribale inventée pour nos trois adultes.

Bureau : 3×2, 75 matériaux + 25 acier, 2 800 unités Core avant matériau ; tailleur : 3×1, 75 bois ou acier, 2 000 avant matériau, vitesse ×0,5. Les deux sont déplaçables. Passage actuel 50 Core (=5 locaux), contre 70 dans l'ancien XML : retenir les données actuelles. Chemise : 45 tissus, 2 700 unités Core avant facteurs. Seul le tissu est livré ; les autres textiles et recettes restent absents.

Recherche personnelle : minimum 0,1 ; Intellect `0,08 + 0,115 × niveau`, Vue et Manipulation à 50 % d'importance, plafond de capacité 1,1, lumière commune. Bureau simple ×0,75, mauvais rôle intérieur ×0,8. La propreté intérieure reste neutre car sols/saleté/nettoyage ne sont pas livrés ; dehors ×0,75 pour cette composante. Le malus extérieur supplémentaire **×0,9 est provisoire** : le wiki le marque « Verify », l'ancien XML donne ×0,75. Cette divergence demeure ouverte. Température ×0,7 sous **9** ou au-dessus de **35 °C**, d'après la classe datée déjà confrontée dans [confection](tailoring-reference.md), contre « sous 10 » dans le résumé wiki. Ne pas annoncer une parité numérique intégrale.

Les chercheurs réévaluent après 4 000 ticks Core (400 locaux), avec notre ordonnanceur commun. Les bureaux équivalents sont choisis par proximité accessible, pas par évaluation exhaustive du meilleur environnement ; priorité entre bureaux de rendements différents reste à affiner. Le tabouret réellement utilisé donne le confort existant. Les livres, analyseur, bureau avancé, niveaux technologiques et le reste de l'arbre sont différés.

Révision rétroactive : le parcours long a montré une annulation répétitive du bois destiné à cuisiner sous forte faim. La livraison du combustible culinaire continue désormais comme la préparation alimentaire. Cette correction de blocage ne modifie ni quantités, ni régimes, ni nutrition ; malnutrition et décès par faim restent absents.
