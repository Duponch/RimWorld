## Sources recoupées et limites de version

Le miroir C# fixé à `2d508035082e7cb0c8e29e230d26bda6e546928f` (20 mai 2026) n'identifie pas avec certitude le binaire commercial ; les correctifs officiels ultérieurs empêchent de promettre une parité exhaustive. La page communautaire [Weapons](https://rimworldwiki.com/wiki/Weapon), relue le 18 septembre, recoupe les trois phases, l'immobilité pendant préparation/récupération et l'absence générale de munitions. Les branches précises proviennent du miroir, pas d'une déduction de ce résumé. Certaines URLs brutes ont échoué via le lecteur Web ; les fichiers correspondants avaient été récupérés depuis le même commit pour la lecture locale. Pas de copie de leur code dans le moteur.

## Adaptations et manques explicites

Notre journée conserve dix ticks Core par tick local. Les sous-pas garantissent 18 puis 96, sans cadence arrondie. Le déplacement déjà capturé se termine avant visée, adaptation à nos trajectoires 3D persistantes. Ordre simultané par identifiant, refus atomique d'un groupe et absence de poursuite automatique sont les contrats explicites du premier outil. Les phases médicales/HUD ont la résolution du tick local, les balles une position interpolée au sous-pas confirmé.

La revue des frontières a ajouté le refus d'un ordre reçu pendant le franchissement d'une case sans arrêt ordinaire. Cela évite de stationner sur le volume d'une table par annulation du trajet ; choix 3D cohérent avec V22, explicitement distinct d'une parité Core certifiée. Le scénario conserve le trajet et la sauvegarde strictement identiques après ce refus.

Le pouvoir d'arrêt du revolver devrait ralentir un humain ; [Weapons, Stopping power](https://rimworldwiki.com/wiki/Weapon#Stopping_power) indique 83 % de ralentissement pendant 95 ticks Core. Ce consommateur est maintenant intégré en **V57**, après [relecture du renouvellement et du paiement minimal de déplacement](stagger-reference.md). Les réactions aux menaces restent absentes. Les jauges de préparation/récupération décrites dans la même page restent à ajouter ; posture armée et libellés sont déjà visibles. Ni cette première commande ni les statistiques définies ne constituent le combat complet.

La relecture finale de [Rest](https://rimworldwiki.com/wiki/Rest), le même jour, confirme l’effondrement involontaire et le sommeil immédiat au sol. Le contrat d’épuisement V12/V53 reste prioritaire sur la posture de tir ; la récupération ne doit pas retarder cet arrêt forcé. La revue a corrigé cette interaction, testée pendant visée, récupération mobilisée et récupération après démobilisation, avec continuation exacte. La précision de l’ordonnancement au tick local reste une adaptation.
