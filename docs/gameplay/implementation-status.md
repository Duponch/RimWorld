# Ce qui est jouable et ce qui manque

**État du dépôt au schéma 162.** Le [mix sonore V163](../development/audio-mix-v163.md) étend la couverture et règle les deux caméras dans le périmètre de sa [preuve](../history/validation-audio-mix-v163.md). La [facture de plats raffinés végétariens par quatre V162](../development/fine-vegetarian-bulk-v162.md) est livrée dans le périmètre de sa [preuve](../history/validation-fine-vegetarian-bulk-v162.md) : contrôles ciblés, régression hors campagnes longues, build, présentation et Chromium préparé passent. Deux microbancs CPU suggèrent un surcoût isolé potentiel sans conclusion générale. Le [plat raffiné mixte par quatre V161](../development/fine-meal-bulk-v161.md) est livré dans le périmètre de sa [preuve](../history/validation-fine-meal-bulk-v161.md). « Livré » désigne une boucle accessible et vérifiée dans le périmètre de sa preuve ; cela ne signifie pas parité complète avec RimWorld Core. Les descriptions de versions anciennes sont conservées dans l’[inventaire archivé](implementation-status-pre-v145.md).

Les [contrats](../README.md), le [guide joueur](player-guide.md) et le [catalogue](content-catalogue.md) donnent le détail des commandes et objets. La [validation courante](../development/validation.md) précise les contrôles récents et la dette de suite historique : les reprises Atterrissage J18→J24, puis J22→J24 après correctif visiteur, et Énergie J42 passent ; un départ frais Atterrissage s’est arrêté à J22 sur le conflit de repas. La régression V145 avait passé 274 fichiers, ainsi que le build avec typage ; les contrôles V149 ont leur propre preuve. Les estimations V124 et les anciennes tables sont des photographies datées, pas des statistiques de couverture actuelles.
