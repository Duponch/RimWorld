# V257 — projection végétale structurelle incrémentale

Qualification privée puis **rejet au seuil de coût fixé avant mesure**. Aucun oracle natif complet de scène, GAME, build ou promotion ; produit V242/schéma 198 et 62 références/65 fichiers publics conservés. Aucun FPS ajouté. [Recherche](../research/source-structural-projection-v257.md), [preuves](../history/validation-source-structural-projection-v257.md).

V256 transformait les changements ordinaires de membership ou de classe en seed numérique complet. Chaque seed recopiait les entrées, réinitialisait l'agenda, renouvelait la génération et faisait perdre le suffixe MAIN. V257 retire cette cascade pour les deltas structurels nominaux. Il change une seule feuille du candidat V256 : `src/bridge/source-vegetal-projection.ts`. Les 855 fichiers de la base couplée restent privés ; les 42 différences avec le produit comprennent cette base non promue.

## Traitement des mutations

Le producteur applique removed, upsert puis growth avant de contrôler le nombre final de membres. Les suppressions retirent les sources possédées, valeurs, échéances et cultures correspondantes. Les entrées nouvelles copient leurs primitives utiles et reçoivent un rang append sûr ; les survivants gardent leur rang relatif, même si kind ou classe change. Chaque ID ne peut être touché qu'une fois par publication ; une trace incompatible décline la projection et efface son état.

Nature→crop émet une tombe naturelle ; crop→nature émet une valeur absolue. Le tableau agricole conserve l'ordre global : suppression locale et insertion binaire par rang lors des transitions, puis packing complet au C publié. Les shifts O(nombre de cultures) restent payés. Une suppression puis renaissance sur deux publications conserve la distinction avec l'ancien C.

La génération numérique reste stable sur ces changements nominaux. Un ordre arbitraire explicite, checkpoint, changement de contexte/epoch ou risque de dépassement des rangs conserve le full historique. L'agenda reçoit les vrais removed/present ; ses cellules, heap, mathématiques, bissections et échéances restent littérales. Une transition sans plante éligible→avec plantes garde son initialisation potentiellement complète, au coût explicite.

## Frontières conservées

Encodeur, lecteur strict, moteur, bootstrap fermé, wire, journal MAIN et couches de scène restent V256. Aucun World fourni par un appelant ne reçoit une autorité nouvelle ; le contrat est toujours une paire numérique explicite et cohérente, distincte du mandat readonly. Un Worker source, une publication native et un strict lecteur MAIN demeurent dans le coût.

MAIN garde les historiques par ID, 64 records et leur budget ; A→C est composé depuis la dernière scène présentée, D reçu ne remplace pas C. Les gardes, suffixes manquants, évictions, repli public et restauration restent ceux de V256. Le vrai journal structurel Decoder peut encore imposer une capture complète de Nature ; le producteur incrémental ne supprime pas cette frontière. Les tableaux agricoles sont toujours continus à la cadence d'origine.

La génération est préparée par ROOT sur un miroir exact avec hash parent, ancres strictes et inverse entier. Les étapes de gel sont chaînées. Les modules d'oracle dormants sont copiés pour leur résolution Vite, mais leur chargement et leurs observations sont interdits dans le mode coût. A reste le produit V242 ; B paie tout le candidat couplé V255/V256/V257.

## Qualification et décision

Dix composants passent : sept Source et trois consommateurs. Ils utilisent de vrais Encoder/Decoder et les queries RAW sur des Worlds préparés ; les deux lecteurs témoins des cas consommateurs appartiennent aux oracles, pas au pipeline mesuré. Ils couvrent membership/classes, rangs/cultures, suppressions/renaissances, C après D, rétention, repli et valeurs. Ils ne certifient pas une campagne native, la factory MAIN, le Core complet ou le GPU.

Le coût ABBA de 96 vrais ticks passe avec états finaux/RNG exacts. Le candidat n'émet plus qu'un full sur 97 paquets pour chaque corpus. Sur Aulnes, le circuit diminue de 1,99 % et le callback MAIN de 11,46 % ; mixed reste presque neutre sur le circuit. Le seuil préalable exigeait 5 % de circuit, ou 20 % de callback avec plafonds de circuit/source. Il n'est pas atteint.

Décision : arrêt de cette piste sans grand oracle géométrique, GAME, build, promotion ou deuxième coût inchangé. Le gain local du callback est conservé dans les preuves ; il ne constitue pas un gain FPS livré ou un résultat suffisant pour la suite de qualification choisie.
